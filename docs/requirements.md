# effort-mind 要件

## 目的

新しいことを意識すると、さっきまで意識していたことを忘れてしまう。
「意識すること」をスマホに貯めておき、忘れてもすぐ戻れるようにする。

## ユーザーと利用場面

- まずは自分専用。チャレンジしている人のためのアプリ。
- 格ゲー（スト6 など）: 試合の合間に見る。
- スノーボード: リフトの上で見る。

## 用語

| 用語 | 意味 |
|---|---|
| 意識すること（項目） | 「対空は昇竜を早めに」のような1件のメモ |
| 今意識する3つ | フォルダごとに目立たせて表示する項目 |
| ストック | 今は意識しないが残しておく項目 |
| 卒業 | 身についたので普段は表示しない項目 |

## 主な機能

### 階層フォルダ

- 項目は階層フォルダで分類する。
  - 例: `スト6 › ケン › 対ルーク`、`スノボ › カービング`
- 上のフォルダ（親・祖父母）に書いた項目も、下のフォルダを開いたときに表示する。
  - 全キャラ共通の項目は上のフォルダに1回書けば済む。
  - どのフォルダに書いた項目かを表示で見分けられるようにする。

### 今意識する3つ

- フォルダごとに3つを目立たせて表示する。上限は設定で変更できる（初期値 3）。
- アプリが直近10回の ○× から、× が多い3項目を自動で選ぶ。
- 手動で入れ替えた項目は、自動選択より優先する。
- 3つ以外の項目は畳んでおき、押すと開く。

### ○× の記録

- いつでも項目ごとに 1 タップで ○ か × を付けられる。
- 練習の開始・終了は記録しない。回数は ○× を押した回数で数える。

### 卒業

- 5回連続で ○ が付いた項目に「卒業しますか？」の印を出す。基準は設定で変更できる。
- 押して確定すると卒業一覧へ移る。

## 作り方とデータ

- Web アプリとして作る。Android 専用の機能には頼らない。
- 電波が無くても動くこと（リフトの上で使うため）。
- データは使っているブラウザ内だけに保存する。ログインとサーバーは使わない。
- 端末間の移行は、ファイルの書き出しと読み込みで行う。

## スコープ外（最初の版ではやらない）

- ログインとサーバー同期
- 通知
- ウィジェットやロック画面への表示
- タグによる分類
- 練習の開始・終了の記録
